# ADR-0001：采用前后端分离架构

- 状态：Accepted
- 记录日期：2026-07-30
- 类型：回溯记录

## 背景

项目需要真实运行、持续扩展、独立部署，并能清楚展示前端、后端和接口边界。

## 候选方案

1. Spring Boot 服务端渲染。
2. Vue 单页应用与 Spring Boot REST API 分离。

## 决策

采用 Vue 3 单页应用与 Spring Boot REST API 分离，前端通过统一 API 客户端访问后端，Docker 环境由 Nginx 提供入口和反向代理。

## 影响

- 前后端可以独立构建和测试。
- 公共 API 契约必须同步维护。
- 鉴权、跨域、代理和错误响应需要明确统一。
