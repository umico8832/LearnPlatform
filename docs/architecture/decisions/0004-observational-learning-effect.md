# ADR-0004：学习效果统计只表达观察性关联

- 状态：Accepted
- 记录日期：2026-07-30
- 类型：回溯记录

## 背景

AI 资产查看、同题作答、跨题迁移和变式训练来自真实行为日志，但当前没有随机实验条件，样本还可能受到用户基础、课程和多资产暴露影响。

## 决策

学习效果面板只报告观察性关联。方向判断必须同时满足最低作答量和去重学习者覆盖；样本不足时保持 `INSUFFICIENT_DATA`。多资产重叠样本不直接用于排名或自动推荐。

## 影响

- 不把 AI 调用量、生成次数或完成按钮当作学习效果。
- 不从当前统计推断因果关系。
- 进入课程或用户基础分层前必须先积累足够真实样本。
