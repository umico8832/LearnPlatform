# ADR-0003：通过 Provider 抽象隔离 AI 上游

- 状态：Accepted
- 记录日期：2026-07-30
- 类型：回溯记录

## 背景

AI 功能需要同步、流式、用量记录和可配置模型支持，同时不能让业务服务直接绑定单一上游实现。

## 决策

通过 `AiProvider` 抽象统一同步和流式能力，由具体 Provider 处理上游协议，业务服务负责学习场景、缓存、配额、审计和降级规则。

## 影响

- 可以替换兼容上游而不重写业务层。
- Provider 必须准确处理异常、流式事件和真实 usage。
- 不支持 usage 的上游保持空值，不进行虚构估算。
