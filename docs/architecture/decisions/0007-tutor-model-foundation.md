# ADR-0007：Tutor 的模型契约与调用治理

- 状态：Accepted
- 记录日期：2026-09-12
- 关联：[ADR-0003](0003-ai-provider-abstraction.md)

## 背景

原 Provider 以两个字符串输入、文本输出和线程局部用量支持生成场景，无法完整表达工具调用、
多轮工具结果、结构化输出和异常终止。各领域分别编排审计，配额的先检查后写日志存在并发窗口。

## 决策

后端采用 Maven `ai-core` 与 `app` 两个模块，仍部署一个 Spring Boot 进程。
`ai-core` 不依赖 Spring、数据库或课程领域；`app` 负责配置、调用准入、审计及业务校验。

核心模型契约使用项目类型。云适配采用 LangChain4j 1.20.0 的底层 API，不使用自动工具执行循环
或 Spring Starter。HTTP 观察器校验上游终止协议，保留原始 usage 中实际存在的字段，并在进入
框架错误处理前移除上游错误正文。JSON Schema 使用固定的 2020-12 方言，拒绝外部引用。

所有领域生成通过 `AiInvocationService`。调用前在独立短事务中锁定用户、检查当日已登记次数、
插入 `RUNNING` 记录；事务提交后才请求云 API。结束时更新同一记录，未知用量保持空值。
一次 HTTP 请求中的多次云调用分别占用配额和记录成本，SDK 自动重试关闭。

## 影响与取舍

- 旧 REST/SSE 的内容协议保留；无用户身份的内部生成入口拒绝调用。
- 工具定义和结果协议已经可用，工具授权与执行、Tutor Runtime 尚未实现。
- 工具和原生结构化输出能力必须显式配置，不因端点兼容就推断模型支持。
- `RUNNING` 记录计入配额，完成日志与运营成功率排除未确认记录。进程崩溃或完成审计失败时，
  记录保留为未确认，不能伪造失败用量、释放已消费配额或宣称上游未计费。
- 不在长数据库事务中等待模型。领域事务回滚也不会删除已提交的调用记录。
- 流式取消停止后续业务回调；无首事件的底层连接最多等待网络超时，取消不保证上游停止计费。
- 本阶段不自动修复或重试输出。后续如加入修复，每次修复都必须重新经过准入与审计。

## 验证边界

云协议通过隔离 HTTP 服务验证，配额与迁移通过真实 MySQL 测试验证。框架契约测试、固定业务
评测和真实云模型教学评测分别记录；模拟上游的通过不代表云模型教学质量通过。
