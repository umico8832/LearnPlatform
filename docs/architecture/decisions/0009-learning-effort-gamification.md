# ADR-0009：从学习事件派生学习投入激励

- 状态：Accepted
- 记录日期：2026-09-30
- 类型：产品与数据架构

## 背景

学习端需要更清晰的作答反馈和长期坚持激励，同时保持真实判分、课程状态与学习效果证据的边界。
统一课程学习事件已经覆盖练习、复习、考试、测评、试卷学习和 Tutor 检查，具备事实来源和幂等标识。

## 决策

经验、等级、每日目标、连续学习天数和成就表达学习投入，从真实持久化学习事件派生，
不新增另一套课程掌握状态，也不推断学习效果或因果关系。判分、奖励和成就由后端认定。

奖励流水关联源事件并受唯一约束保护；同一题同一自然日的重复作答保留业务历史，但不重复获取经验。
游戏化聚合与事件写入同事务完成，用户级行锁保护并发聚合。自然日沿用项目 `Asia/Shanghai` 口径；既有学习事件的无时区 `DATETIME` 先按应用写入时的 JVM 源时钟解释，再换算为该口径；
今天尚未作答而昨天已有作答时保留连续天数。未判分题不按答对奖励。
该用户的历史事件通过一次性、幂等补算进入同一流水，重复运行不会增加奖励。
精确规则与字段由游戏化 API、数据库参考及服务实现共同维护。

学习端保持 Vue 3、Element Plus 和共享 CSS tokens；激励元素采用鲜亮语义色，阅读区域保持清晰克制。
反馈组件和单一庆祝调度承载经验增长、连续作答、升级与成就；简单过渡使用 Vue/CSS，
稀有庆祝按需加载 `canvas-confetti`，后续动画依赖需有实际能力需求和兼容性、体积证据。

## 不变量

- 浏览、生成、添加课程、填写自评和确认计划不产生作答奖励。
- 客户端不认定经验、等级、连击、成就或学习目标完成。
- 限时考试提交前不展示正确性、连击、经验、庆祝或声音反馈。
- 动效可打断、可关闭且不延迟操作；reduced-motion 保留结果并消除非必要位移、缩放、彩纸和循环。
- 游戏化缓存与待播放反馈绑定账号，退出、换号及进入考试时清理。

## 影响

奖励可追溯、可重新核对；后端新增派生存储与接口，并需要真实 MySQL 验证幂等、并发和迁移。
前端提交响应与跨页概况共享同一真实数据来源；新增展示及反馈必须覆盖空状态、失败和快速连续操作。
本决策承接 [ADR-0004](0004-observational-learning-effect.md) 与 [ADR-0005](0005-course-learning-state.md)。
