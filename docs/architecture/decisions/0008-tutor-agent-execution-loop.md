# ADR-0008：Tutor Agent 可控执行循环与恢复边界

- 状态：Accepted
- 记录日期：2026-09-20
- 关联：[ADR-0007](0007-tutor-model-foundation.md)

## 背景

模型契约已经支持工具消息和逐次调用审计，但原有 Tutor 仍是已审查静态内容与一次理解检查，
不能接受学习者追问，也没有可恢复的 Agent 运行。若直接使用框架自动工具循环，工具授权、循环上限、
每次云调用配额和课程所有权会被隐藏在框架行为中。

## 决策

Tutor Agent 由应用层显式执行模型循环。每次模型调用都通过 `AiInvocationService`，同一运行共享
`run_id`，但分别登记配额、用量、成本和终止原因。单次用户消息最多允许三轮工具结果回填；模型若
跳过必需的已审查课程内容工具、调用未注册工具或继续无限请求工具，整次运行失败且不保存不完整回答。

首批工具只读取当前用户、当前课程、当前 Tutor 会话绑定的已审查教学内容和学习证据快照。工具参数
不接受课程、用户或内容 ID，避免模型扩大服务端已经确定的资源范围；工具结果移除理解检查答案与解释。

`tutor_agent_run` 保存 `RUNNING`、`WAITING_USER`、`FAILED` 状态，`tutor_agent_message` 只保存成功完成后
对用户可见的 USER / ASSISTANT 消息。状态领取与消息追加使用短事务和条件更新，等待云模型时不持有数据库
事务。失败运行可由同一用户在原 Tutor 会话中恢复；同一运行不能并发处理两条消息。

## 影响与取舍

- 模型和工具能力未显式启用时，Tutor 会话不展示 Agent 入口；原有教学、检查、练习和考试继续可用。
- 对话正文是用户可恢复功能数据，与不保存 Prompt 正文的 `ai_call_log` 审计日志分开管理。
- 当前只提供同步问答和读取工具，不支持后台自主运行、任意代码、写学习事实或中途取消上游计费。
- 浏览器标签页保存不敏感的会话与运行标识，用于刷新恢复；服务端仍重新校验用户、课程、会话和审查状态。
- 进程在状态回写前异常退出可能留下 `RUNNING`，后续需要基于运行租约或明确恢复策略治理，不能自动猜测
  上游是否完成或是否计费。

## 验证边界

运行时单测覆盖工具先行、循环上限、工具白名单、答案隔离、所有权、并发领取、失败恢复和前端刷新恢复；
Flyway 集成测试覆盖从上一版本升级及消息序号唯一约束。真实云模型的工具遵循率、教学质量、成本与延迟
仍需独立评估。
