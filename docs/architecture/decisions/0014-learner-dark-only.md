# ADR-0014：学员端新页面只用深色

- 状态：Accepted
- 日期：2026-10-18

## 背景

[ADR-0011](0011-living-textbook-spring-motion.md) 规定新基线同时提供浅色与深色，页面跟随系统外观。
展示首页已固定为深色。用户只用深色、觉得浅色刺眼，Phase 28 还要重做学员端其余二十余个页面，
每页都检查两种外观的成本很高，而浅色没有目标用户。

## 决策

学员端从 Phase 28 起新做或重做的页面只用深色：页面根节点固定 `data-appearance="dark"`，
只检查深色，不提供外观切换。`--lt-` token 继续用 `light-dark()` 定义，不删除浅色取值，
以便将来恢复浅色时不必重写组件。

Phase 28 之前已按新基线完成的页面，除已固定深色的展示首页外，暂时保持跟随系统，阶段末由用户决定是否一并固定为深色。

## 影响

修改 ADR-0011 中“同时提供浅色与深色”的要求，仅适用于学员端；其余视觉、弹簧动效与组件约定不变。
管理端不受影响。浅色取值不再随页面验收，恢复浅色前需重新检查对比度与层次。
