# AI 题库与错题复习系统 - 演示流程

本文档用于指导项目演示，涵盖所有核心功能模块的操作步骤。

---

## 演示准备

### 环境启动

#### 方式一：本地开发
```bash
# 1. 启动 MySQL
sudo /usr/local/mysql/support-files/mysql.server start

# 2. 初始化数据库（首次）
mysql -u root -p < backend/src/main/resources/db/schema.sql

# 3. 启动后端
cd backend
mvn spring-boot:run

# 4. 启动前端
cd frontend
npm install
npm run dev
```

#### 方式二：Docker Compose
```bash
cp .env.example .env
docker compose up -d
docker compose ps  # 确认所有服务正常
```

## 演示流程

### 第一部分：用户端功能演示（使用 testuser 登录）

#### 1. 登录注册

1. 打开前端页面，进入登录页
2. 演示注册新用户（可选）
3. 使用 testuser/test123 登录
4. 登录成功后自动跳转首页

**演示要点**：
- JWT Token 自动注入
- 登录状态持久化（刷新页面不丢失）
- 401 自动跳转登录页

---

#### 2. 首页学习面板

1. 登录后查看首页统计卡片
   - 总刷题数、正确率、今日刷题、连续学习天数
2. 查看 ECharts 图表
   - 7 天刷题趋势柱状图
   - 课程正确率雷达图
3. 使用快捷入口跳转

**演示要点**：
- 数据可视化（ECharts）
- 统计接口聚合查询
- 空状态友好展示

---

#### 3. 课程与知识点浏览

1. 点击侧边栏"课程列表"
2. 浏览课程卡片列表
3. 点击某个课程进入详情页
4. 查看知识点树形结构

**演示要点**：
- 课程列表分页加载
- 知识点树形展示（el-tree 组件）
- 响应式布局

---

#### 4. 题库浏览

1. 点击侧边栏"题库"
2. 使用筛选条件（题型、课程、难度）
3. 浏览题目卡片（题干、选项、知识点标签）
4. 分页浏览

**演示要点**：
- 多维筛选功能
- 题目类型标签区分
- 分页组件

---

#### 5. 在线刷题

1. 点击侧边栏"刷题练习"
2. 查看练习统计卡片
3. 配置刷题参数：
   - 选择课程（可选）
   - 选择题型（可选）
   - 选择难度（可选）
   - 设置题目数量
4. 点击"开始练习"
5. 答题演示：
   - 单选题：点击选项
   - 多选题：勾选多个选项
   - 判断题：选择正确/错误
   - 填空题：输入答案
6. 提交后查看结果弹窗（对错、正确答案、解析）
7. 完成后查看练习总结

**演示要点**：
- 多题型交互
- 自动判分逻辑
- 即时反馈

---

#### 6. 刷题记录

1. 点击侧边栏"刷题记录"
2. 查看历史记录列表
3. 使用筛选条件（题型、结果）
4. 分页浏览

---

#### 7. 错题本

1. 点击侧边栏"错题本"
2. 查看统计卡片（总错题数、各掌握程度数量）
3. 使用掌握程度筛选
4. 浏览错题卡片
5. 演示掌握程度切换（未掌握 → 部分掌握 → 已掌握）
6. 演示移出错题本操作

**演示要点**：
- 答错自动收集机制
- 掌握状态管理
- 统计分析

---

#### 8. 模拟考试

1. 点击侧边栏"考试"
2. 查看已发布试卷列表
3. 开始考试：
   - 进入答题界面
   - 查看倒计时功能
   - 逐题作答
4. 提交试卷（或等待超时自动提交）
5. 查看考试结果：
   - 得分、正确率
   - 答题详情
6. 切换到"考试记录"标签查看历史

**演示要点**：
- 倒计时功能（剩余 5 分钟红色警告）
- 超时自动提交
- 成绩分析

---

#### 9. AI 辅助功能

1. 点击侧边栏"AI 复习建议"
2. 选择课程（可选）
3. 点击"生成复习建议"
4. 查看 AI 生成的 Markdown 内容

**演示要点**：
- AI Provider 抽象层设计

## 演示注意事项

1. **提前准备测试数据**：确保数据库中有课程、知识点、题目等测试数据
2. **AI 功能降级演示**：如未配置 API Key，展示友好提示信息

4. **浏览器**：推荐使用 Chrome，确保开发者工具可随时打开

## 测试数据初始化

如果数据库为空，可通过以下步骤初始化测试数据：

1. 执行建表 SQL：
```bash
mysql -u root -p < backend/src/main/resources/db/schema.sql
```

2. 使用管理员账号登录后端接口文档（http://localhost:8080/doc.html）

3. 通过接口创建测试数据：
   - 创建课程（POST /api/admin/courses）
   - 创建知识点（POST /api/admin/knowledge-points）
   - 创建题目（POST /api/admin/questions）
   - 创建试卷（POST /api/admin/exam-papers）

4. 使用普通用户账号进行刷题、考试等操作产生数据
