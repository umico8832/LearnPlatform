# 演示检查清单

## 环境

- [ ] `.env` 使用本地示例配置，没有准备展示真实秘密。
- [ ] `docker compose ps` 或本地前后端状态正常。
- [ ] `/api/public/health` 返回成功。
- [ ] Knife4j 可以打开。
- [ ] 演示浏览器没有残留错误账号和过期 Token。

## 数据

- [ ] 存在至少一个课程和知识点树。
- [ ] 存在覆盖主要题型的正式题目。
- [ ] 存在一份已发布试卷。
- [ ] `testuser` 有可展示的练习、错题和复习数据。
- [ ] 存在可展示的投稿、纠错或版本记录。
- [ ] AI 页面有真实缓存或已配置可用 Provider。

## 主线

- [ ] 登录、练习、错题和复习闭环可以完成。
- [ ] 考试可以开始、提交并查看结果。
- [ ] 管理员能够展示投稿审核和显式入库。
- [ ] 普通用户访问管理接口返回 403。
- [ ] AI 不可用时降级信息清楚，核心功能仍正常。

## 表述

- [ ] 不把演示数据说成真实生产数据。
- [ ] 不把观察性学习效果说成因果提升。
- [ ] 不声称尚未实现的 OCR、自动入库或复杂推荐。
- [ ] 不展示真实 API Key、Cookie、JWT 或数据库密码。

## 备用材料

- [ ] `docs/showcase/screenshots/` 中截图与当前界面一致。
- [ ] README、简历表述与真实实现一致。
- [ ] 准备本地录屏或截图，以应对网络或 AI 上游故障。
