# 演示流程

以“一道题从错到懂”为主线，建议 8–10 分钟：英文首页 → 原题作答 → 所选错项的误区 → 三级提示与本题动画 → 正解 → 无提示变式 → 复习。演示真实权限、服务端判分与学习记录；模型质量另有评测，不能用确定性隔离上游的画面证明教学效果。

## 准备

按[本地开发](../getting-started/local-development.md)或[Docker 开发](../getting-started/docker-development.md)启动，排障见[常见问题](../getting-started/troubleshooting.md)。主要展示尺寸为 1440 × 900；公开首页使用匿名状态，学习端与管理端使用各自地址。

| 角色 | 本地演示账号 | 本地演示密码 |
| --- | --- | --- |
| 学习者 | `testuser` | `test123` |
| 管理员 | `admin` | `admin123` |

账号仅用于本地演示。主线优先使用本轮独立学习者，避免旧作答、追问次数或复习卡影响结果；隔离 E2E 的账号创建与流程可参考 `frontend/e2e/question-understanding.spec.ts`。不通过清除用户学习记录准备演示。

开始前确认：

- `/api/public/health` 正常，学习端可以登录，管理员接口仍按角色校验。
- “408 数据结构”课程可加入课程库，出栈序列预置题的理解内容、提示和变式通过正式审核门禁。
- 若演示追问，确认开关、Provider 与额度可用；未配置时跳过该段，确定性提示与主学习流程仍可展示。
- 真实密钥、Cookie、JWT、登录输入不进入录屏。外部模型与认证凭据的真实闭环以实际验收为准。

## 主线：一道题从错到懂

### 1. 首页，约 1 分钟

匿名打开 `/`，展示英文首屏的轮换词与演示卡、可交互路网、链表实验室和示意复习日历。点实验室的代码入口可以看同一次模拟执行的代码视图。导航与页脚的 Product、Learning、Resources、Roadmap、About 等链接中有公开占位页，讲解时如实说明。

首页是能力展示入口。路网为首页演示，正式可视化场景仍是链表、出栈序列、二叉树三类；日历为示意数据。不要把演示卡或日历说成当前学习者的真实记录。

### 2. 选错一道题，约 1 分钟

登录后进入“我的课程”，从课程库加入“408 数据结构”，进入课程主线页，打开题干“入栈顺序为 1,2,3,4,5，下列哪个是可能的出栈序列？”的题目。按题干定位，数据库自增 ID 不作为固定演示地址。

选 B 并提交，出现“以为能越过 2 直接弹出 1”的误区，只解释刚选的错项。此时正解尚未开放。说明题面、作答归属、审核版本和判分依据由服务端校验，不能靠前端隐藏答案保证安全。

### 3. 提示与动画，约 2 分钟

依次领取“给我一点提示”“再具体一点”“看一个相似的例子”，观察提示逐级展开及来源标记。完整已审核提示链适用时，原题答错须先领完三级提示才能揭示正解。

播放“用你选的 3,1,2,5,4 走一遍”的动画；在 `stack-buried` 检查点先预测下一次能否弹出目标，再继续看结果。可演示嵌入与整页展开后返回同一位置。动画来自本题参数与确定性模拟器，不执行模型生成的代码；不同题目可以没有动画。

若追问可用，可问“为什么不能直接取出下面的元素？”。未解锁时生成模型只拿学习者已可见材料，回答完整缓冲后经过规则和独立判断；最多重生成一次，再失败返回安全引导。解锁后允许完整解释，仍检查材料口径。此处展示产品边界，实际回答、延迟和教学质量以真实评测为准。

### 4. 正解与变式，约 2 分钟

三级提示后点“看正解”，查看正确选项与逐步解释，再做“换一个条件，再做一次”的变式。答案提交前由服务端保管；同一原尝试的变式重试返回首次结果，不能靠重复提交刷出新的评分。

本次原题领过提示或预占过追问，因此变式会标为辅助作答，不更新 FSRS 排期。另起一次未领提示、未预占追问的原尝试可以展示独立变式计分。用页面返回的“本次计入”和“下次复习”解释差别；揭示正解本身不替代这些辅助判定规则。

### 5. 错题与复习，约 1 分钟

进入错题页，查看这道题最近的所选错项误区与真实重做日期；进入复习页，展示到期队列与返回理解页的入口。没有到期题时如实展示空态，不为了演示改日期或修改学习事实。FSRS 根据独立作答安排间隔，不能承诺准确预测遗忘时刻。

正式理解流程、辅助判定与复习返回字段见[题目理解 API](../reference/api/question-understanding.md)和[题目导师 API](../reference/api/question-tutor.md)。

## 按面试方向补充

| 方向 | 可选演示 | 要讲清的边界 |
| --- | --- | --- |
| 内容治理 | 管理员预览树章节待审核题、投稿审核与显式入库 | 预览不写学习记录，待审核题不向学习者开放，AI 不自动发布 |
| 考试一致性 | 试卷学习、限时考试、提交与主观题批阅 | 学习与考试状态机分离；未批阅保持待判分，客户端不决定总分 |
| AI 工程 | 流式增量、取消、历史、配额与调用审计 | 同一追问计一次配额，各次生成/判断分别计用量；真实价格配置后才固化成本 |
| 学习投入 | 个人日历、目标、经验与真实统计 | 投入记录不等于掌握度，观察性差异不等于因果提升 |
