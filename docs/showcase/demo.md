# 演示流程

本演示以真实接口、真实权限和真实判分展示完整学习闭环。建议控制在 15–20 分钟，不逐页罗列所有 CRUD。

## 主线一：学习闭环

使用 `testuser`：

1. 登录并进入学习工作台。
2. 从课程进入知识点和题库。
3. 选择练习条件并回答至少一道题。
4. 展示后端判分、正确答案和解析。
5. 故意答错一道题，进入错题本确认自动收集。
6. 将错题加入或同步到间隔复习，提交一次复习质量。
7. 查看学习报告、薄弱知识点或错因分析。

重点说明：

- 提交前不泄露答案；
- 判分、错题同步和复习调度都在后端；
- 统计来自真实练习记录。

## 主线二：真题学习与考试

1. 将 408 数据结构加入个人课程库，打开已核验的 2026 年 408 数据结构部分试卷，核对 13 题、45 分和来源。
2. 先用学习模式逐题作答，展示即时判分、解析、原始题号和首次作答后的上下文 AI 辅导入口。
3. 再开始限时考试，展示服务端倒计时和答题状态。
4. 提交试卷，查看客观题暂定分和第 41、42 题待人工批阅状态；此时不展示主观题参考答案。
5. 切换管理员进入“主观题批阅”，逐评分点给分并提交总体评语；全部批完后切回学习者查看固化总分。
6. 返回考试记录确认结果已保存；可从错题或课程入口继续复习。

重点说明：

- 后端锁定考试记录并校验归属、题目集合和时限；
- 试卷学习与限时考试使用不同状态机，学习模式不会削弱考试约束；
- 已发布试卷和已提交结果受不可变规则保护；
- 主观题评分点总分由发布门禁约束，客户端不能跳过评分点或提交越界得分；
- 客户端不能自行决定总分。

## 主线三：AI 学习资产

在题目学习页：

1. 展开一种 AI 学习资产。
2. 展示流式内容、Markdown 安全渲染或可视化讲解。
3. 提交资产反馈。
4. 打开结构化变式训练。
5. 提交答案并展示服务端首次判分。

若未配置 AI Key，展示明确的降级提示，并使用已经缓存的演示资产；不要伪造实时生成成功。

重点说明：

- 生成、缓存和真实查看是不同事件；
- 变式题正确答案不下发到前端；
- AI 上游失败不影响核心学习闭环。

## 主线四：内容治理

切换到 `admin`：

1. 查看管理总览。
2. 打开投稿审核，展示 AI 质检、知识点和难度建议。
3. 由管理员显式审核和入库。
4. 在正式题目中展示来源、纠错、复审或版本记录。
5. 展示发布后题目和试卷的修改限制。

重点说明：AI 只辅助审核，不自动发布题目或修改标准答案。

## 主线五：AI 运营治理

1. 打开 AI 调用分析。
2. 展示调用、成功率、Token、成本、模型和功能分布。
3. 查看用户配额与调整审计。
4. 查看提醒和确认流程。
5. 打开学习效果观察，说明样本门槛和 `INSUFFICIENT_DATA`。

重点说明：

- Token 来自上游 usage；
- 未知价格不伪造成本；
- 效果数据是观察性关联，不是因果结论。

## 真实截图

隔离 E2E 环境生成截图：

```bash
docker compose -f docker-compose.yml -f docker-compose.e2e.yml up -d --build --force-recreate --wait
cd frontend
npm run screenshots:demo
```

默认访问 `http://localhost:18000`，输出到 `docs/showcase/screenshots/`。自定义地址：

```bash
DEMO_BASE_URL=http://localhost:5173 npm run screenshots:demo
```

脚本遇到页面加载阶段的 4xx/5xx API 响应会失败，避免生成不可信截图。
