本演示以真实接口、真实权限和服务端判分展示完整学习闭环。建议控制在 15–20 分钟，不逐页罗列所有 CRUD。隔离演示环境可使用确定性 AI 服务验证会话、流式协议与业务状态；这类画面不作为真实云模型教学或内容质量的证据。

## 主线一：课程学习闭环

使用本轮创建的隔离学习者：

1. 登录后默认进入「我的课程」，从真实课程卡片开始学习。
2. 从课程库查看 408 计算机统考分类，了解 408 数据结构课程并加入课程库。
3. 进入课程空间：查看继续学习目标、课程目录、学习工具与真实学习事实。
4. 从目录进入 AI 教学：分步讲解、互动课件（如栈、队列可视化）与服务端判分的理解检查。
5. 完成练习并故意答错一道题，进入错题页确认自动收集；标记掌握程度或重练。
6. 从课程空间进入复习，处理到期复习；再次作答确认状态更新。
7. 完成一次阶段测评，查看题源构成、按知识点统计与逐题复盘。

重点说明：

- 提交前不泄露答案；
- 判分、错题同步和复习调度都在后端；
- 课程空间只展示真实学习事实（作答数、错题数、到期复习数），不伪造掌握度。

## 学习投入记录

1. 将课程加入个人课程库，完成一题真实练习，展示服务端判分、解析和原位“本次记录 +N 经验”。
2. 完成本组练习，展示已判分正确率、待判分数量、已答数、经验与成就文字；错题重练正确时，服务端同步移出错题本。
3. 打开个人中心，展示从学习事件汇总的等级、今日已答/目标、成就进度和学习日历；修改每日目标并刷新确认持久化。
4. 切换系统减弱动效，确认数值、判分和下一步仍清楚；限时考试作答保持静默，交卷结果仅展示真实学习记录与待批阅语义。

经验与等级记录真实投入。未加入个人课程库、未判分或同对象同日重复作答可以没有经验，不为演示修改规则。当前界面不使用连击徽章、彩纸、浮层奖励或动画化经验结算；演示用原创隔离题目与账号，录制结果存于忽略目录。

## 主线二：真题学习与考试

1. 将课程加入个人课程库，在已发布试卷中打开运行时核验的正式试卷，展示实际题量、分值和来源。
2. 先用学习模式逐题作答，展示即时判分、解析、原始题号和首次作答后的上下文 AI 辅导入口。
3. 再开始限时考试，展示服务端倒计时、答题状态和离开保护。
4. 提交试卷，查看客观题暂定分和实际待人工批阅项；此时不展示主观题参考答案。
5. 切换管理员进入“主观题批阅”，逐评分点给分并提交总体评语；全部批完后切回学习者查看固化总分。
6. 返回考试记录确认结果已保存；可从错题或课程入口继续复习。

重点说明：

- 后端锁定考试记录并校验归属、题目集合和时限；
- 试卷学习与限时考试使用不同状态机，学习模式不会削弱考试约束；
- 已发布试卷和已提交结果受不可变规则保护；
- 主观题评分点总分由发布门禁约束，客户端不能跳过评分点或提交越界得分；
- 客户端不能自行决定总分。

## 主线三：AI 学习资产

在题目学习页：

1. 展开一种 AI 学习资产。
2. 展示流式内容、Markdown 安全渲染或可视化讲解。
3. 提交资产反馈。
4. 打开结构化变式训练。
5. 提交答案并展示服务端首次判分。

若未配置 AI Key，展示明确的降级提示，并使用已经缓存的演示资产；不要伪造实时生成成功。

重点说明：

- 生成、缓存和真实查看是不同事件；
- 变式题正确答案不下发到前端；
- AI 上游失败不影响核心学习闭环。

## 主线四：内容治理

切换到 `admin`：

1. 查看管理总览与真实加载、空态或失败重试状态。
2. 打开投稿审核，展示 AI 质检、知识点和难度建议；提交期间锁定动作，失败后保留审核草稿以便重试。
3. 打开 AI 变式审查，展示批准或驳回说明仍由管理员确认。
4. 打开主观题批阅，逐评分点给分并提交总体评语；提交期间不允许改写评分对象。
5. 在正式题目中展示来源、纠错、复审和版本记录；由管理员显式将已通过的投稿入库。

重点说明：AI 只辅助审核，不自动发布题目、修改标准答案或替代主观题评分。

## 主线五：AI 运营治理

1. 打开 AI 调用分析。
2. 展示调用、成功率、Token、成本、模型和功能分布。
3. 查看用户配额与调整审计。
4. 查看提醒和确认流程。
5. 打开学习效果观察，说明样本门槛和 `INSUFFICIENT_DATA`。

重点说明：

- Token 来自上游 usage；
- 未知价格不伪造成本；
- 效果数据是观察性关联，不是因果结论。

## 真实截图

单页截图优先复用已核对的本地开发页面；公开首页在匿名状态下截图，学习工作台与管理端再分别登录。
学习端与管理端使用各自的开发地址，按
[浏览器验收 Skill](../../.agents/skills/frontend-flow-test/SKILL.md)验证内容后取图。
截图完成后保留用户原本启动的服务。

批量截图脚本分别接收学习端 `DEMO_BASE_URL` 与管理端 `DEMO_ADMIN_BASE_URL`，可在本地分地址环境运行。
正式录制应显式启用 `DEMO_ISOLATED=1`，让脚本创建唯一学习者和本轮 fixture；输出目录也应显式指向忽略路径。例如：

```bash
cd frontend
DEMO_BASE_URL=http://127.0.0.1:15173 \
DEMO_ADMIN_BASE_URL=http://127.0.0.1:15174 \
DEMO_ISOLATED=1 \
DEMO_SCREENSHOT_DIR=tmp/quiet-showcase \
npm run screenshots:demo
```

脚本以 1440 × 900 拍摄；短录屏保留正常动效，首页与个人页另验减弱动效。覆盖匿名首页、课程空间、Tutor、练习闭环、考试结果和个人页，并只在各画面的真实状态稳定后输出 PNG 或短 WebM。脚本失败或页面加载中的 4xx/5xx 不能作为截图验收通过；截图完成后保留用户原本启动的服务。
[正式 E2E 命令](../development/testing.md#8-浏览器-e2e-环境)结束后会清理隔离环境，不能在它退出后假定该环境仍供截图使用。
