# AI 题库与错题复习系统 - 后续扩展方向

本文档记录项目的后续扩展方向和功能规划，供后续迭代参考。

## P0：核心体验提升

### 1. AI 功能整合到刷题/错题页面 ✅

**完成情况**：已在刷题结果弹窗和错题卡片中接入 AI 深度解析、变式题生成，并复用统一的 Markdown 展示组件。

**目标**：在刷题结果弹窗和错题本卡片中直接嵌入"AI 解析"和"生成变式题"按钮。

**涉及文件**：
- `frontend/src/views/practice/PracticeSessionView.vue` — 答题结果弹窗增加 AI 按钮
- `frontend/src/views/practice/WrongQuestionView.vue` — 错题卡片增加 AI 按钮
- 可复用 `MarkdownRenderer.vue` 组件

**预计工作量**：0.5-1 天

### 2. AI 流式输出（SSE）

**完成情况**：已为题目解析和变式题新增带 JWT 的 POST SSE 接口，前端通过 `fetch + ReadableStream` 实时追加 Markdown 内容；原同步接口继续保留。

**现状**：AI 接口为同步调用，用户需等待全部生成完毕才能看到结果，体验差。

**目标**：使用 Server-Sent Events 实现流式输出，用户可逐字看到 AI 生成内容。

**涉及改动**：
- 后端 `AiController` 新增 SSE 接口（`text/event-stream`）
- 后端 `OpenAiProvider` 支持流式读取 `stream: true`
- 前端使用 `EventSource` 或 `fetch + ReadableStream` 接收

**预计工作量**：1-2 天

### 3. 管理端统计面板 ✅

**完成情况**：已实现管理端平台总览，包含核心指标、题型分布、近 7 日活跃趋势和用户/试卷状态。

**目标**：管理端首页显示平台概览数据。

**展示内容**：
- 注册用户总数
- 题目总数（按题型分布）
- 试卷总数（已发布/草稿）
- 今日活跃用户数
- 本周新增题目数

**涉及改动**：
- 后端 `StatisticsController` 新增 `/api/admin/statistics/overview` 接口
- 前端新建 `AdminDashboard.vue`

**预计工作量**：1 天

## P1：重要功能补充

### 4. 用户个人中心

**现状**：用户无法修改个人信息（昵称、头像、密码）。

**功能**：
- 修改昵称
- 修改密码（需验证原密码）
- 头像上传（可选，或使用 Gravatar）
- 个人学习报告（本月刷题量、正确率趋势）

**涉及改动**：
- 后端 `UserController`（PUT /api/user/profile、PUT /api/user/password）
- 前端 `ProfileView.vue`
- 路由和导航更新

**预计工作量**：1 天

### 5. 错题重练模式

**现状**：错题本只支持查看和管理，不支持直接从错题本发起重练。

**功能**：
- 错题本页面新增"重练错题"按钮
- 支持按掌握程度筛选后重练
- 重练答对后自动更新掌握程度或移出

**涉及改动**：
- 后端 `PracticeService` 新增 `getWrongQuestionPractice()` 方法
- 前端 `WrongQuestionView.vue` 增加重练入口
- 前端 `PracticeSessionView.vue` 支持错题重练模式标识

**预计工作量**：0.5-1 天

### 6. 题目收藏/标记功能

**现状**：用户无法收藏重要题目。

**功能**：
- 题目卡片上增加收藏按钮（星标）
- 收藏列表页面
- 收藏题目可直接发起练习

**涉及改动**：
- 新建 `user_favorite_question` 表
- 后端 `FavoriteService` + `FavoriteController`
- 前端 `FavoriteView.vue`
- 刷题页面和题库页面增加收藏按钮

**预计工作量**：1 天

### 7. 题目导入/导出

**现状**：题目只能逐条手动录入，效率低。

**功能**：
- Excel/CSV 批量导入题目
- 题目模板下载
- 导出题目为 Excel

**涉及改动**：
- 后端引入 Apache POI 或 EasyExcel
- `AdminQuestionController` 新增 import/export 接口
- 前端管理端增加导入/导出按钮

**预计工作量**：1.5 天

## P2：锦上添花

### 8. 学习计划与提醒

**功能**：
- 设置每日刷题目标（如每天 20 题）
- 首页显示今日目标进度
- 连续打卡天数激励
- 学习周报（可选：邮件/站内通知）

**预计工作量**：1-2 天

### 9. 社区/讨论功能

**功能**：
- 题目下方添加评论/讨论区
- 用户可分享解题思路
- 点赞优质评论

**预计工作量**：2 天

### 10. 多端适配优化

**现状**：前端使用 Element Plus，基本支持响应式，但未针对移动端优化。

**功能**：
- 移动端导航适配（抽屉式侧边栏）
- 答题界面移动端优化（触摸友好的选项点击）
- 统计图表响应式适配

**预计工作量**：1-2 天

### 11. 题目难度自适应

**功能**：
- 根据用户答题记录动态调整推荐题目难度
- 答对率高的知识点推荐更难题目
- 答对率低的知识点推荐基础题目

**涉及改动**：
- `PracticeService` 推荐算法优化
- 可基于简单加权算法或 ELO 评分

**预计工作量**：1-2 天

## P3：远期规划

**功能**：
- 支持机构/班级创建
- 教师可管理学生账号

**功能**：
- 使用 uni-app 或原生开发移动端

- 推送通知

**预计工作量**：10+ 天

### 14. AI 增强功能

**功能**：
- 智能组卷（AI 根据知识点和难度自动组卷）
- 学习路径推荐（AI 根据薄弱点推荐学习顺序）
- 知识图谱可视化

**预计工作量**：5+ 天

**功能**：
- Redis 缓存（题目缓存、统计数据缓存）
- 接口限流（防止恶意刷题）

- 监控告警（Prometheus + Grafana）
- CI/CD 流水线（GitHub Actions）

**预计工作量**：3-5 天
