# API 通用约定

## 业务时间

全平台业务时区固定为 `America/New_York`，每日 AI 配额、复习“今天”、学习连续日和日历均按纽约自然日计算，
与服务器、浏览器的机器时区无关。无偏移的日期时间字段表示纽约本地时间；纯 `YYYY-MM-DD` 表示业务日期。
考试 `serverTime`、`deadline` 返回带当时 UTC 偏移的 ISO 8601；时长按实际经过分钟计算，跨夏令时切换不增减。
存量存储分类与换算边界见[数据库时间语义](../database/time-semantics.md)。

## 请求

| 项目 | 约定 |
|---|---|
| 内容类型 | 默认 `application/json` |
| 认证 | `Authorization: Bearer <token>` |
| 用户接口 | `/api/**`，除公开接口外需要登录 |
| 管理接口 | `/api/admin/**`，需要管理员角色 |
| 时间 | 后端统一序列化格式以运行时 Jackson 配置和 OpenAPI 为准 |

文件上传接口使用 `multipart/form-data`；SSE 流式接口返回 `text/event-stream`。

## 统一响应

普通 JSON 接口使用统一响应外壳：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

`data` 的具体结构以对应 DTO 和 OpenAPI 定义为准。流式接口不使用该 JSON 外壳，而是连续发送 SSE 数据片段。

## 错误语义

| code | 语义 |
|---:|---|
| `0` | 成功 |
| `1001` | 参数校验失败 |
| `1002` | 未登录或 Token 无效 |
| `1003` | 权限不足 |
| `1004` | 资源不存在 |
| `1005` | 业务规则拒绝 |
| `1007` | 容量限制或可重试写入冲突，具体行为见领域契约 |
| `5000` | 未处理的服务端异常 |

HTTP 状态和业务 `code` 共同表达结果。客户端不得只依赖响应文案判断分支。
数据库死锁或锁等待超时会整体回滚，并返回JSON业务码1007、文案“写入冲突，请重试”。
带幂等键的写请求重试时保留原UUID及原请求体；响应已经成功但丢失时仍返回首次结果。
成功幂等快照按纽约时区至少保留7个自然日；清理后相同键会按新请求处理，客户端不能依赖超过窗口的重放结果。

## 分页

列表接口通常使用 `page`、`pageSize` 以及领域筛选参数。实际响应可能是 MyBatis-Plus 分页对象或项目分页 DTO，前端应以对应 API 类型定义为准。

## 安全边界

- 用户端题目详情不得返回选项正确标记和标准解析。
- 考试答案由后端根据已锁定试卷配置判分，客户端分数不可信。
- 已发布试卷及其引用题目的修改、删除受业务规则限制。
- AI 调用日志不得保存真实 API Key、Token 或未经处理的隐私数据。
- 管理端批量导入、导出和审核接口必须经过角色校验。
