## Round 172：成熟认证体系

### 完成内容

- 用 Cloudflare Turnstile 前后端完整校验替换图片验证码。
- 登录支持用户名或验证邮箱，并继续保留 JWT、角色、状态和失败限流规则。
- 新注册用户必须完成邮箱验证码和一次性注册票据闭环，历史账号允许暂时没有邮箱。
- 新增忘记密码、重置链接验证和一次性密码重置流程；重置后旧 JWT 失效。
- 新增 Mailpit 本地邮件接收服务和 SMTP、Turnstile 环境变量契约。
- 登录、注册、忘记密码和重置密码页面统一为响应式认证工作台视觉。
- 数据库升级到 V20，增加邮箱身份、认证版本、邮箱验证和密码重置表。

### 安全边界

- Turnstile 前端成功状态不受信任，后端必须向 Cloudflare `siteverify` 二次校验。
- 邮箱验证码、注册票据和密码重置令牌不保存明文。
- 注册票据与重置令牌均由数据库条件更新保证一次性消费。
- 忘记密码使用中性响应，不披露邮箱是否存在。
