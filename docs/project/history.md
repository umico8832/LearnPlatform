# 项目里程碑

本文只记录影响产品定位、主要能力或长期架构的项目级结果。具体实现、普通修复和单次验证由 Git 与 CI
保存；当前阶段、验证边界和遗留问题见[项目状态](status.md)。

| 时间 | 里程碑 | 最终结果 |
|---|---|---|
| 2026-06 | 核心学习平台 | 建立 Vue、Spring Boot、MySQL 与 Docker 项目骨架，打通认证、课程、题库、练习、错题、复习、考试和基础 AI 能力。 |
| 2026-07 | AI 学习与内容治理 | 形成学习资产、可视化讲解、题目投稿与审核、全局搜索、间隔复习、调用成本治理和观察性学习效果能力。 |
| 2026-08 | 课程学习平台转型 | 建立个人课程库、统一课程学习事件、Web Tutor、课程阶段测评和 2026 数据结构真题学习闭环。 |
| 2026-08 | 管理端与私有试卷 | 学习端和管理端独立构建；支持有限文本、PDF、DOCX 私有试卷导入、人工复核、所有者隔离和原文件配额。 |
| 2026-08 | 展示版收口 | 统一 Quiet Digital Textbook 视觉和学习信息架构，完成项目级回归后进入维护阶段。 |
| 2026-09 | 工程结构治理 | 拆分高耦合前后端职责，建立代码结构、文档、开发环境、提交和验证门禁。 |
| 2026-09 | Tutor 模型与认证底座 | 后端拆分为应用与 AI 核心模块，增加云模型契约、原子配额审计和可配置 Google OIDC 登录。 |

重大取舍及其约束由[架构决策](../architecture/decisions/index.md)维护；工程审计结论见
[审计归档](audits/index.md)。
