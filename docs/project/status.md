## 当前阶段

- Phase 21“前端信息架构与视觉体验优化”：已完成。

当前主线是将现有刷题、考试和 AI 题目学习底座转型为以课程长期学习过程为中心的
Web 优先平台。第一步先定义统一课程学习状态，再用 408 数据结构跑通 AI 教学与
真题学习共享状态的最小闭环。

首个后端切片已建立个人课程库、跨端稳定内容标识，并从 AiStu 迁入 408 数据结构课程
及 8 个顶层章节。加入课程仍与开始学习和掌握证据严格分离；已加入课程库后的练习、
复习、考试和结构化 AI 变式题首次判分，会以可追加、可幂等的课程学习事件保存。

## 当前遗留问题

- 前端 ESLint 无阻断错误，但仍有存量显式 `any` 警告，应按修改范围逐步收紧。
- 生产依赖审计仍有 ECharts 中危公告，升级存在破坏性变化，应配合可视化页面回归单独处理。
- Phase 22 的真实样本尚不足以支持课程或用户基础分层结论。
- 当前用户端和管理端仍在同一个 Vue SPA 中，独立前端应用只是已接受的迁移目标。
- 当前课程、题库、会话、错题和复习数据尚未形成统一课程学习状态。
- 个人课程库已接入前端；课程总览、进度聚合和“开始学习”目标选择尚未实现。
- AiStu 的 408 顶层目录已首批迁入；原子知识、Tutor 逻辑和互动课件尚未迁入 Web。
