## 当前遗留问题

- 未运行真实 Google OIDC、真实 Cloudflare Turnstile 凭证闭环或真实云模型评测；2026-09-26 执行环境未注入聊天与 Embedding 必需配置，首批知识内容仍待人工审核；日常后端未由本轮重启应用 V99/V100/V101/V102。
- Spring Boot 3.2.5 与 Knife4j 4.4.0 的主版本升级需要单独兼容性迁移；当前已加入 Dependabot 和全依赖审计，不能把自动升级等同于兼容性验证。
- 前端仍有较集中的样式与组件维护债务：若干单文件组件接近结构门禁上限，`HomeView.css` 仍较大，原始颜色/颜色函数尚未完全迁移到设计令牌。
- 课程和知识点引用保护目前由服务校验与事务提供；在缺少数据库外键或一致锁策略时，极端并发下“校验后新增引用”的竞态仍需后续治理。
- 真实学习样本不足以支持课程或用户基础分层结论；现有学习效果指标仅表达观察性关联。
- 学习端与管理端共享依赖工程、基础 API/鉴权及静态镜像，这是 [ADR-0006](../architecture/decisions/0006-separate-learner-admin-frontends.md) 的既定边界。
- 扫描件 OCR、复杂版式、更多课程、画像和桌面端同步尚未实现，均不阻止维护任务完成。
- PRD 的自动审查 Agent 仍是产品目标；当前正式题发布由管理员批准，不据文档目标改变实现权限。
