## 当前前端视口范围

- 当前阶段只开发和验收桌面 Web，默认支持宽度不低于 `1280px` 的桌面浏览器，并以 `1440 × 900` 作为主要视觉检查尺寸。
- 除非用户在具体任务中另有要求，不为手机或平板新增适配，不把移动端截图、布局检查或浏览器回归纳入完成条件。
- 保留已有响应式实现，不主动删除或破坏现有移动端能力；项目进入移动端阶段后再由用户明确调整本节范围。
