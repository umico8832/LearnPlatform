- 最近一次结构回归未确认本机 Docker daemon 可用；本次没有检测运行环境，E2E 栈是否在线未知。
- 真实学习样本不足以支持课程或用户基础分层结论；现有学习效果指标仅表达观察性关联。
- 学习端与管理端共享依赖工程、基础 API/鉴权及静态镜像，这是 [ADR-0006](../architecture/decisions/0006-separate-learner-admin-frontends.md) 的既定边界。

- PRD 的自动审查 Agent 仍是产品目标；当前正式题发布由管理员批准，不据文档目标改变实现权限。
