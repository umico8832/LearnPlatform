# 学习内容讲解口径

本页统一题干、选项、错因、分级提示、正解、变式与可视化场景的数学和程序约定。当前覆盖 408 数据结构的线性表、栈与队列、二叉树；新增主题先在本页补充约定，再批量写内容。题目原文若明确规定另一种表示，优先遵守题目原文，并在讲解开头指出差异。真实 408 题只在逐题核对题号、选项与答案后标注来源；本站生成的讲解和题目在审核前标为“AI 生成·待审核”，通过后标为“AI 生成·已审核”并记录实际审核方式（如 AI 初稿 + Codex 冷读 + Claude 页面审核）。

## 术语与记号

| 概念 | 本站写法与含义 |
|---|---|
| 数据元素的位序 | 逻辑表中第 `1` 至第 `n` 个元素；空表没有第 1 个元素。`i` 表示位序时明确写“第 i 个”。 |
| 数组下标 | C 风格数组从 `0` 开始；逻辑第 `i` 个元素对应 `data[i-1]`。不要把位序直接当下标。 |
| 头指针、头结点、首元结点 | 头指针是变量，指向头结点（若有）；头结点不存有效表元素，首元结点才是第 1 个数据结点。若题目声明无头结点，另按其结构处理。 |
| 结点、指针域 | 中文正文统一写“结点”；`p->next` 是结点 `p` 的指针域，`p` 是指针变量。 |
| 栈顶、队头、队尾 | 分别指当前可弹出的栈元素、当前可出队元素、最后入队元素；涉及数组指针时另写其所指位置，不能从这些名称推断下标。 |
| 先序、中序、后序、层序 | 分别为“根·左·右”“左·根·右”“左·右·根”“自上而下、每层从左到右”。所有子树递归使用相同顺序。 |

此处的逻辑位序与数组下标区分是**本站约定**；教材和实现可以选不同的下标模型。[清华大学出版社《数据结构》第 2 版目录](https://www.tup.tsinghua.edu.cn/bookscenter/bookcatalog?id=05360101)分别以“第 i 个位置”讲顺序表及带头结点单链表的插入，[OpenDSA List ADT](https://opendsa.org/OpenDSA/Books/Catalog/html/ListADT.html)则在程序列表模型中明确采用从 0 开始的位置。内容必须写出所选模型，不能把某一实现说成所有教材的唯一定义。

## 线性表与单链表

- 顺序表长度为 `n` 时，插入到第 `i` 个位置要求 `1 ≤ i ≤ n+1`；删除第 `i` 个元素要求 `1 ≤ i ≤ n`。表头插入需将原有元素后移，表头删除需将剩余元素前移；表尾操作无需移动已有元素。这与[2026 年 408 数据结构第 1 题](https://www.csgraduates.com/study_methods/408quiz/2026/)的题意及答案一致。
- 默认单链表**带头结点**：`L` 指向头结点，头结点在遍历计数中记为第 `0` 个，数据结点的逻辑位序从 `1` 开始。插入第 `i` 个位置要找到第 `i-1` 个结点 `p`，先令 `s->next = p->next`，再令 `p->next = s`；删除第 `i` 个数据结点也先找到其前驱。清华大学出版社的[教材目录](https://www.tup.tsinghua.edu.cn/bookscenter/bookcatalog?id=05360101)将带头结点建表与第 i 个位置插入并列讲述；本站具体 `p/j` 计数以[链表场景实现](../../frontend/src/viz/scenes/linked-list/index.ts)为准。
- 指针赋值按代码先后发生，不能把两句赋值当成同时交换。原地逆置时 `prev` 初值为 `NULL`，最后必须更新 `L->next = prev`；仅改变数据结点指针不能自动改变头结点。动画的“可达”指沿当前 `next` 从头结点可访问，不等于结点在内存中存在。
- 题目若涉及无头结点、循环链表、静态链表或下标从 0 起，题干必须先声明该表示，错项讲解不得沿用上述默认。

## 栈与队列

- 栈按后进先出解释。给定固定入栈顺序时，每个元素须先入栈，出栈只取当前栈顶；检查候选出栈序列时，按输入顺序压到目标已入栈，再核对目标是否位于栈顶。不能从栈中间抽取元素。[本站栈场景](../../frontend/src/viz/scenes/stack/index.ts)的 `next` 是“下一个待入栈的值”，`k` 是候选输出数组的 0 起下标，它们都不是栈顶下标。
- 若题目使用**栈顶指针指向当前栈顶元素**的顺序栈，空栈设 `top=-1`，入栈先 `++top` 再写入，出栈先读取再 `top--`。[清华大学出版社顺序栈教材节选](https://www.tup.tsinghua.edu.cn/upload/books/yz/041764-01.pdf)采用这一表示。也存在把 `top` 设为首个空位、空栈 `top=0` 的教材实现，例如 [OpenDSA Array Stack](https://opendsa.org/OpenDSA/Books/Catalog/html/StackArray.html)；题目采用后者时必须在题干说明，不能混写两套满空条件。
- 队列按先进先出解释。本站默认的循环队列以 `front` 指向队头元素、`rear` 指向下一个可写空位，初始 `front=rear=0`，保留一个空槽区分满与空：空为 `front==rear`，满为 `(rear+1)%M==front`，可存 `M-1` 个元素，长度为 `(rear-front+M)%M`。这是[清华大学出版社教材节选](https://www.tup.tsinghua.edu.cn/upload/books/yz/095552-01.pdf)列出的一种常用方案；若题目使用计数器、标志位或让 `rear` 指向最后一个元素，须重新写明初值、更新顺序与满空条件。

## 二叉树与遍历

- 二叉树的左右孩子有序，不能互换。先序访问根再左再右；中序先左再根再右；后序先左再右再根；层序按层从左到右。[清华大学出版社树遍历教材节选](https://www.tup.tsinghua.edu.cn/upload/books/yz/100257-01.pdf)给出同一递归顺序。
- 从中序与层序重建时，当前子树的根是其层序中最早出现的结点；在**当前子树的中序片段**按根切成左右两段，再分别递归。不能用整棵树的层序邻接关系直接判断左右孩子。[2026 年 408 数据结构第 3 题](https://www.csgraduates.com/study_methods/408quiz/2026/)按此得到后序 `e,f,d,c,b,g,a`、选 C。
- 本站 `binary-tree` 场景的 `tree` 参数是含 `null` 空孩子标记的层序序列；`null` 不作为结点访问，尾部空标记可省。代码内部根深度为 `0` 仅用于布局；向学习者描述层数时根为第 `1` 层。动画里的 `return` 返回直接调用者，不会跳到根重新遍历。

## 讲解与场景校验

1. 先写可核对的结构或状态，再给结论。错项讲解只分析**本次选中的选项**为何在具体一步违背不变量；不把错项当作学习者实际想法，也不从一次作答推断长期薄弱点。
2. 提示依次给概念方向、推理步骤、相似案例，均不直接排除选项或泄露答案；完整答案只在正解开放后给出。题干、选项、提示、误区、正解、变式与动画标题中的代码表达式一律用 Markdown 反引号包裹（如 `p->next=s`、`data[i-1]`、`Push(1)`、`front==rear`），以等宽形式呈现。讲解用 C 风格短伪代码，`NULL`、`->`、`++`、`--` 与语句顺序明确；若伪代码省略边界检查，须标为示意，不当作可运行程序。
3. 动画 `spec` 只给场景、操作、**本题实际数据**与停顿点，由确定性模拟器求过程。`pauseAt` 的检查点 ID 必须存在；答案、选项、正解、变式数据与模拟结果一致。无匹配场景的题目不强配动画，记入候选场景清单。
4. 原创题注明“原创”；真实试题记录年份、题号及可访问链接，逐题核对后才能标“来源已核对”。AI 生成内容默认“AI 生成·待审核”；内容审核只改变内容审核状态，不能替代外部试题的逐题来源核验。
