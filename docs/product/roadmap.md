## Phase 0–11：核心业务闭环

目标是建立可运行、可部署、可演示的前后端分离学习平台。

已完成：

- Vue 3、Spring Boot、MySQL、Flyway 和 Docker 项目骨架。
- 注册登录、JWT、角色权限和验证码。
- 课程、知识点、题库和多题型管理。
- 练习、判分、记录、错题和重练。
- 试卷、考试、倒计时、判分和成绩分析。
- AI 解析、复习建议和统计可视化。
- 测试、部署、README、演示和简历材料。

## Phase 12：体验增强

目标是在核心闭环上补齐常用学习和运营能力。

已完成：

- AI 流式输出。
- 收藏、评论、学习计划和学习报告。
- 导入导出、健康检查、监控和缓存。
- 管理端用户、课程、题目和试卷体验增强。

后续只按真实需求迭代，不再作为独立主线堆叠功能。

## Phase 13：AI 题目学习资产

已完成：

- 多种学习资产生成和缓存。
- Markdown 安全渲染。
- 用户查看、反馈和管理员观察入口。
- 变式训练与题目学习流程整合。

## Phase 14：AI 可视化交互讲解

已完成：

- 代码执行动画与语法高亮。
- SQL 执行顺序。

## Phase 15：AI 学习画像与个性化推荐

目标是基于练习、错题、复习和 AI 学习行为建立轻量学习画像。

已完成：

- 薄弱知识点与课程掌握诊断。
- 错因、学习习惯和趋势分析。
- 每日推荐与规则建议。
- AI 个性化建议。

## Phase 16：题目投稿与 AI 题库生产

## Phase 22：AI 学习效果验证

目标是从“调用了多少次”推进到“用户实际看了什么、之后表现如何”，但只表达观察性关联。

已完成：

- AI 学习资产真实查看记录。
- 阅读前后同题作答观察。
- 共享知识点跨题迁移观察。
- 按资产类型拆分的同题观察。
- 变式训练开始和显式完成事件。
- 结构化变式题答案服务端保存、首次真实判分和结果锁定。
- 难度 1–5 样本结构与分层就绪度。
- 作答量与去重学习者双门槛。
- 样本不足时返回 `INSUFFICIENT_DATA`。

当前工作与进入下一阶段的条件见[项目状态](../project/status.md)，候选方向见[后续扩展方向](future.md)。

Phase 22 已经建立观察性事件、样本门槛和不足数据语义。真实样本仍可继续积累，但不再
作为产品当前唯一主线；相关能力将作为课程学习状态和未来画像的现有底座继续维护。

## Phase 23：AI 课程学习平台转型

### Goal

把以题库、错题和考试为中心的 Web 项目转型为以课程长期学习过程为中心的 AI 学习
平台，同时复用现有鉴权、题库、判分、考试、复习、内容治理和 AI 运营能力。

已接受的方向：

- Web 是当前主开发端，桌面端等待核心协议稳定后再复用；
- 用户先将课程添加到个人课程库，再进入课程总览持续学习；
- AI 教学和试卷学习是两个并列入口；
- 两个入口必须共享课程学习状态、错题、复习和测评记录；
- 公共题库以权威考试原题试卷为主，用户可以学习自己的私有试卷和题库；
- AI 可以参考母题、课程范围和用户状态生成新题，审查 Agent 通过后进入正式学习流程；
- 用户学习端与管理系统采用独立前端应用目标，共用后端、账号和业务数据；
- 当前保留 Vue 3、Spring Boot 和模块化单体，不为转型立即重写技术栈。

### Exit Criteria（首个阶段验收）

以下业务闭环全部成立即满足退出条件：

- 用户可以添加 408 数据结构课程并进入课程总览；
- 未指定知识点时，“开始学习”可以根据统一状态选择下一教学目标；
- 一次教学能够完成讲解、必要课件、理解检查和学习事件记录；
- 一张官方真题可以在学习模式中获得 AI 辅导，作答进入同一课程状态；
- 错题可以从课程总览进入复习，并影响后续 AI 教学上下文；
- 用户可以主动完成课程阶段测评，测评结果进入同一错题、复习和课程事件状态；
- 已实现的有限结构化私有试卷导入必须保持所有者隔离；尚未实现的复杂资料解析、画像和桌面同步不会被
  文档或界面宣称为完成；
- 学习端与管理端应用职责边界清晰，核心流程拥有真实自动化验证。

Exit Criteria 是否已满足、Remaining Required 与 Backlog 的当前状态以
[项目状态](../project/status.md) 为准（截至 2026-08：Exit Criteria 全部满足、
Remaining Required 为空，阶段已完成退出）。

### 执行顺序与完成情况

1. 重置产品文档、阶段状态和架构决策；已完成。
2. 定义统一课程学习状态、事件和跨入口不变量；已完成。
3. 用 408 数据结构跑通课程库、课程总览与“开始学习”；已完成。
4. 接入讲解、前置补充、现有课件和理解检查；已完成（ArrayStack、ArrayQueue、
   DualArrayDeque、RootishArrayStack、线性表、栈、队列等已审查 Web Tutor 模块）。
5. 用一张结构化真题跑通学习、考试和复盘；已完成（2026 数据结构真题，含可信来源、
   原始题号、主观题人工批阅与 45 分分卷）。
6. 打通 AI 教学、题目作答、错题和复习；已完成（Tutor 跨入口学习上下文、试卷学习
   AI 辅导）。
7. 建立独立管理端应用并迁移现有管理页面；已完成（正式 `/admin/`）。
8. 扩展用户上传、更多课程、画像、可视化升级和桌面端：
   - 已完成：结构化 Markdown/文本、文本型 PDF 与有限 DOCX 私有试卷的预览—确认—
     学习/考试闭环、无答案客观题草稿—AI 建议—逐题人工复核—启用闭环、受限原文件
     存储/配额/清单/受引用保护删除；课程阶段测评最小闭环（错题/到期复习/近期错误
     优先选题、快照判分、历史与逐题复盘、题源构成、知识点限定与按知识点统计）；
     AI 生成题管理端审查队列与测评接入。
   - 未完成部分（扫描件 OCR、复杂版式、自动公开）以及更多课程、画像、可视化升级、
     桌面端属于 Phase 23 Backlog 或下一阶段，不阻止当前阶段退出。

### Backlog / Follow-up（不阻止 Phase 23 退出）

- 课程总览按知识点的学习事实面板（从课程学习事件、错题、到期复习与测评逐题快照
  按知识点聚合事实计数并联动既有入口）。
- 更多筛选维度、对称入口与 UI 增强。
- Tutor 内容继续扩张（408 其余原子知识与其他课程）。
- 扫描件 OCR、图片/公式还原和复杂版式识别。
- 学习画像、复杂个性化、可视化整体重做、AiStu 桌面端同步、复杂向量推荐。

### Stop / Transition Condition

Exit Criteria 全部满足后 Phase 23 必须结束，不因仍可继续优化而继续加 Required；
后续按 roadmap / future 进入扩展课程与内容、画像、可视化升级和桌面端等方向。
