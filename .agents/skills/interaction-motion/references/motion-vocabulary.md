# Motion vocabulary

Use these terms to clarify a request, not to prescribe an effect.

| Term | Meaning |
| --- | --- |
| Fade | Opacity changes without spatial travel. |
| Translate / slide | An element moves along an axis. |
| Scale-in | An element enters slightly smaller and settles to its final size. |
| Origin-aware transition | A surface scales or moves from its triggering control rather than its center. |
| Stagger | A small, ordered delay across a group; it must not delay interaction or reading. |
| Crossfade | Outgoing and incoming content overlap through opacity. |
| Continuity transition | Motion connects before and after states so the user keeps orientation. |
| Accordion / collapse | A section exposes or hides content through a layout change. |
| Press feedback | Brief visual response to activation. |
| Hold to confirm | Progress feedback while a user intentionally holds an action. |
| Drag / swipe to dismiss | A gesture moves a surface; release resolves from position and velocity. |
| Spring | Physics-like settling used when an interruption or gesture needs carried momentum. |
| Interruptible motion | A transition can change target while in flight rather than restarting. |
| Reduced motion | A variant that removes nonessential spatial/repetitive movement while retaining useful state clarity. |
| Jank | Visible stutter caused by missed frames, layout work, paint work, or main-thread contention. |
